# Nodefolio — Interactive Node-Based Computational Portfolio

Computational portfolio of **Shubham Sharma** — AI & Data Science Engineer exploring generative architectures, distributed neural pipelines, and interactive graph systems.

## Features
- **Interactive Node Canvas:** Pan, zoom, and arrange interactive compute nodes with dynamic Bézier wire connections.
- **Dual View Modes:** Toggle between visual node-graph canvas and structured list inspector.
- **Comprehensive Profiles:** Detailed modals for projects, certifications, resume, and contact links.
- **High-Performance Architecture:** Built with Vite, React 19, and Tailwind CSS.

## Tech Stack
- **Framework:** React 19, TypeScript
- **Bundler:** Vite
- **Styling & Animation:** Tailwind CSS, Motion, Lucide Icons

## Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/rosenkrvz/nodefolio.git
   cd nodefolio
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
